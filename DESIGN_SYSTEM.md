# IDEAS 3.0 Design System

## Color Palette

### Primary Colors
- **Royal Blue**: HSL(221, 84%, 24%) - Primary brand color
- **Premium Gold**: HSL(38, 92%, 50%) - Accent and highlights
- **Premium Crimson**: HSL(351, 83%, 47%) - Call-to-action buttons

### Secondary Colors
- **Accent Blue**: HSL(198, 89%, 48%) - Secondary highlights
- **Light Backgrounds**: HSL(221, 83%, 97%) - Subtle backgrounds
- **Dark Text**: HSL(221, 84%, 16%) - Primary text color

### Neutral Colors
- **White**: HSL(0, 0%, 100%) - Backgrounds and cards
- **Light Gray**: HSL(221, 83%, 86%) - Borders and dividers
- **Dark Gray**: HSL(221, 77%, 76%) - Secondary text
- **Black**: HSL(0, 0%, 0%) - Darkest text

## Typography

### Font Families
- **Headings**: Geist Sans (Bold, Semibold)
- **Body**: Geist Sans (Regular, Medium)
- **Monospace**: Geist Mono (for code)

### Font Sizes
- **H1**: 48px (desktop), 32px (mobile)
- **H2**: 36px (desktop), 28px (mobile)
- **H3**: 28px (desktop), 24px (mobile)
- **Body**: 16px (desktop), 14px (mobile)
- **Small**: 14px (desktop), 12px (mobile)

### Line Heights
- **Headings**: 1.2
- **Body**: 1.6
- **Compact**: 1.4

## Spacing Scale

- **xs**: 4px
- **sm**: 8px
- **md**: 16px
- **lg**: 24px
- **xl**: 32px
- **2xl**: 48px
- **3xl**: 64px

## Border Radius

- **sm**: 4px
- **md**: 8px
- **lg**: 12px
- **xl**: 16px
- **2xl**: 24px
- **full**: 9999px

## Shadows

### Elevation Levels
- **sm**: 0 1px 2px 0 rgba(0, 0, 0, 0.05)
- **md**: 0 4px 6px -1px rgba(0, 0, 0, 0.1)
- **lg**: 0 10px 15px -3px rgba(0, 0, 0, 0.1)
- **xl**: 0 20px 25px -5px rgba(0, 0, 0, 0.1)
- **2xl**: 0 25px 50px -12px rgba(0, 0, 0, 0.25)

## Component Styles

### Buttons
- **Primary**: Gradient (Crimson to Red), white text
- **Secondary**: Outline with gold border
- **Tertiary**: Ghost style with hover effect
- **Disabled**: Reduced opacity, no hover effect

### Cards
- **Default**: White background, subtle shadow
- **Elevated**: Larger shadow, hover lift effect
- **Bordered**: Light gray border, no shadow

### Forms
- **Input**: Light gray background, royal blue focus
- **Label**: Dark text, medium weight
- **Error**: Red text, red border
- **Success**: Green text, green border

## Animations

### Transitions
- **Fast**: 150ms
- **Normal**: 300ms
- **Slow**: 500ms

### Easing Functions
- **ease-in-out**: cubic-bezier(0.4, 0, 0.2, 1)
- **ease-out**: cubic-bezier(0, 0, 0.2, 1)
- **ease-in**: cubic-bezier(0.4, 0, 1, 1)

### Common Animations
- **Fade In**: opacity 0 → 1
- **Slide Up**: translateY 20px → 0
- **Scale In**: scale 0.9 → 1
- **Hover Lift**: translateY 0 → -2px

## Accessibility

### Color Contrast
- **Normal Text**: Minimum 4.5:1 ratio
- **Large Text**: Minimum 3:1 ratio
- **UI Components**: Minimum 3:1 ratio

### Touch Targets
- **Minimum Size**: 44x44px
- **Spacing**: 8px minimum between targets

### Focus States
- **Outline**: 2px solid primary color
- **Offset**: 2px from element

## Responsive Breakpoints

- **Mobile**: 320px - 640px
- **Tablet**: 641px - 1024px
- **Desktop**: 1025px - 1440px
- **Large**: 1441px+

## Dark Mode

### Dark Mode Colors
- **Background**: HSL(221, 84%, 4%)
- **Card**: HSL(221, 84%, 6%)
- **Text**: HSL(210, 40%, 98%)
- **Border**: HSL(221, 84%, 16%)

## Usage Guidelines

### When to Use Each Color
- **Royal Blue**: Primary navigation, headers, important elements
- **Gold**: Highlights, accents, call-to-action secondary buttons
- **Crimson**: Primary call-to-action buttons, alerts
- **Accent Blue**: Secondary highlights, hover states

### When to Use Each Component
- **Primary Button**: Main call-to-action
- **Secondary Button**: Alternative action
- **Card**: Content grouping
- **Badge**: Status or category
- **Alert**: Important information

## Brand Voice

- **Professional**: Maintain academic credibility
- **Innovative**: Showcase cutting-edge technology
- **Inclusive**: Welcome all participants
- **Energetic**: Convey excitement and engagement
